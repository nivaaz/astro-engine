# Public V1 scope

## Mission

Open, accurate, deterministic symbolic infrastructure. Outputs are coordinates, context, provenance, and structure—not interpretations.

## Included

- Tropical zodiac and Whole Sign houses
- Current planetary positions and retrograde state
- Moon phase
- Tight conjunction, opposition, square, trine, and sextile aspects with orb and phase
- Bounded upcoming major events
- Saturn-return windows, passes, orb, and upcoming/active/complete status
- Human Design transit gates and lines only
- Browser geolocation or manual latitude/longitude/timezone
- Offline major-city lookup resolving to latitude/longitude/timezone without a third-party geocoding request
- Canonical JSON, Markdown, and prompt-ready plain text
- No-account installable PWA with explicit stale/offline state
- Session-only birth input
- Thin private developer smoke CLI

## Deferred

Public MCP/API, accounts, billing, calendar feeds, public CLI, interpretations, Placidus, sidereal/Vedic, full bodygraph, native mobile, saved profiles, and hosted private data.

## Release gate

GitHub and the PWA ship together only after technical readiness, explicit owner approval, and confirmed signed commercial Swiss Ephemeris terms. Until then, no public deployment or package publication is authorized.
