# Licensing boundary

## Locked posture

Sukara intends to use a commercial Swiss Ephemeris licence. Signed terms have not yet been confirmed for this delivery program.

Until that confirmation and explicit release approval:

- Do not publicly deploy or publish packages that depend on Swiss Ephemeris.
- Do not commit or distribute Swiss source, data, binaries, licence files, or private registry credentials.
- Do not bundle a Swiss adapter into the browser.
- Do not describe the repository as licensed to distribute Swiss assets.

Public MIT packages define and consume an `EphemerisProvider` interface. The commercial Swiss adapter remains private and server-only by default. The public repository contains no production low-precision fallback.

The root MIT licence applies only to original repository code and does not grant rights to third-party Swiss Ephemeris materials.
