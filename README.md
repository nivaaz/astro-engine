# Astro Engine

Open, deterministic symbolic infrastructure for builders and AI workflows, built by Sukara.

Astro Engine provides astronomical coordinates, timing, relationships, provenance, and exportable structure. It does not provide interpretations or spiritual advice.

## Current state

The repository is in the Foundation + Public V1 program. The foundation is intentionally small while canonical contracts and independently validated computation are rebuilt.

Public deployment, package publication, and Swiss Ephemeris distribution are blocked until signed commercial terms and explicit release approval are confirmed.

## Development

```bash
nvm use
npm ci
npm run verify
npm run test:e2e
```

Use Node 24.18.0 and npm 11.16.x. See [the delivery contract](docs/governance/DELIVERY.md), [the repository map](docs/architecture/REPO_MAP.md), and [the active plan](docs/plans/README.md).
